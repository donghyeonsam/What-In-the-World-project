# 실시간 글로벌 이슈 모니터링 플랫폼

## 1. 서비스 개요

세계 뉴스를 수집·분석해 글로벌 이슈와 국가별 관심도·논조·인기 테마를 보여주는 서비스다.

- 비로그인 사용자도 이용 가능
- MVP 대상 국가: 한국, 미국, 일본, 독일, 영국
- 기본 화면: 글로벌 대시보드
- 국가 분석 기본값: 한국

### 주요 용어

| 용어 | 의미 |
|---|---|
| 글로벌 이슈 | 여러 국가에서 공통으로 많이 다루는 주제 |
| 인기 테마 | 한 국가에서 최근 24시간 동안 많이 다룬 주제 |
| 논조 | 기사가 이슈를 긍정·중립·부정 중 어떤 시각으로 다루는지 나타낸 값 |
| 국가 간 관심도 | 한 국가가 다른 국가를 기사에서 언급한 비율 |

## 2. 메인 화면 — MAIN-001

- 상단: 헤더
- 좌측 60%: 지구본
- 우측 40%: 대시보드
- 대시보드 내용이 길면 영역 내부에서 스크롤

### 헤더 — HDR-001

| 구성 | 동작 |
|---|---|
| 로고 | 글로벌 대시보드로 이동 |
| 글로벌 동향 | 글로벌 대시보드 표시 |
| 국가 분석 | 한국 대시보드 표시 |
| 국가 검색·드롭다운 | 국가 선택 후 해당 국가 대시보드 표시 |
| 로그인·회원가입·프로필 | 로그인 상태에 맞게 표시 |

국가는 한글명 또는 영문명으로 검색하며 MVP 5개국만 제공한다.

## 3. 지구본 — GLB-001

- MVP 대상 국가의 위치와 이름 표시
- 드래그 회전 및 확대·축소 지원
- 국가 선택 시 해당 국가 대시보드(DSBD-002) 표시
- 글로벌 이슈 선택 시 국가별 논조를 지구본에 색상으로 표시
- 긍정·중립·부정·데이터 없음 색상과 범례 제공

## 4. 대시보드

### 글로벌 대시보드 — DSBD-001

최초 진입 또는 `글로벌 동향` 선택 시 표시한다.

1. 전체 누적 수집 기사 수
2. 오늘 수집 기사 수(KST 00:00 기준)
3. 글로벌 이슈 TOP 5
4. 이슈 선택 시 이슈 상세(DSBD-003)로 이동

### 국가 대시보드 — DSBD-002

국가 검색, `국가 분석` 또는 지구본에서 국가를 선택하면 표시한다.

1. 선택 국가의 오늘 수집 기사 수
2. 오늘 기사 수 기준 글로벌 순위
3. 최근 24시간 인기 테마 TOP 3
4. 다른 국가에 대한 관심도 TOP 4

#### 화면 동작

- 인기 테마 선택 → 테마 상세(DSBD-005)
- 인기 테마 `더보기` → 인기 테마 전체(DSBD-004)
- 관심도는 가로 막대와 비율로 표시
- `언급한 국가`와 `언급받은 국가`를 버튼으로 전환

### 이슈 상세 — DSBD-003

글로벌 이슈를 선택하면 표시한다.

1. 이슈 제목과 설명
2. 글로벌 논조 비율
3. 국가별 논조와 편차
4. 대표 기사 3개
5. 지구본에 국가별 대표 논조 색상 표시

### 인기 테마 전체 — DSBD-004

국가 대시보드에서 `더보기`를 선택하면 표시한다.

1. 최근 24시간 인기 테마 TOP 10
2. 테마별 기사 수 추이 그래프
3. 테마별 분야와 기사 수
4. 테마 선택 시 테마 상세(DSBD-005)로 이동

### 테마 상세 — DSBD-005

인기 테마를 선택하면 표시한다.

1. 선택 국가와 테마명
2. 대표 기사 10개
3. 기사 헤드라인, 언론사, 발행 시각
4. 헤드라인 선택 시 새 탭에서 원문 열기

## 5. 화면 전환

| 사용자 행동 | 결과 |
|---|---|
| 글로벌 동향 선택 | DSBD-001 |
| 국가 선택 | DSBD-002 |
| 글로벌 이슈 선택 | DSBD-003 |
| 인기 테마 더보기 | DSBD-004 |
| 인기 테마 선택 | DSBD-005 |
| 기사 헤드라인 선택 | 외부 원문 |

## 6. 구현 우선순위

### MVP 필수

- 실시간 글로벌 이슈 TOP 5
- 전체·오늘 수집 기사 수
- 국가별 오늘 기사 수와 글로벌 순위
- 국가 간 관심도
- 이슈별 국가 논조와 국가 내 논조 편차
- 테마별 기사 수 추이
- 테마별 대표 기사와 원문 링크

### 추가 기능

- 로그인·회원가입
- 기사 신뢰도 점수
- 글로벌 이슈별 대표 기사

## 7. 완료 기준

- MVP 5개국을 검색하거나 지구본에서 선택할 수 있다.
- 글로벌 이슈 선택 시 상세 정보와 국가별 논조가 표시된다.
- 국가별 기사 수, 순위, 관심도, 인기 테마를 확인할 수 있다.
- 테마별 기사 추이와 대표 기사 원문을 확인할 수 있다.
- 로딩·빈 데이터·오류 상태를 제공한다.
