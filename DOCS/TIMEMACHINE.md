# 타임머신 조회

기사의 최초 분석 결과(요약·논조·테마)와 최초 이슈 배정이 변경되지 않는다는 전제로, 스냅샷 없이 기존 데이터를 시점 조건으로 조회한다. 별도 테이블이나 마이그레이션은 없다.

## 요청

콘텐츠 조회 GET API에 선택적인 `asOf` 쿼리 파라미터를 전달한다. 생략하면 백엔드에서 요청별 현재 시각을 한 번 확정한다. ISO 8601 오프셋 시각을 받으며, 기존 DB 저장 기준인 KST로 변환한다. 잘못된 형식, 시간대 없는 시각, 미래 시각은 400이다.

```text
GET /api/v1/global/issues?asOf=2026-09-16T01:50:00Z
```

위 요청은 한국 시각 2026-09-16 10:50 기준이다. `+09:00`을 사용할 때 `+`는 URL 인코딩해야 한다. 응답 구조는 기존과 같다.

적용 API:

- `/api/v1/global/issues`, `/api/v1/global/issues/{issueId}`
- `/api/v1/countries/{countryCode}`, `/api/v1/countries/{countryCode}/themes/popular`
- `/api/v1/themes/by-field`, `/api/v1/themes/{themeId}/overview`
- `/api/v1/issues/{issueId}/overview`
- `/api/v1/articles`, `/api/v1/articles/{articleId}`, `/api/v1/articles/filters`

## 조회 기준

- 기사: `created_at <= asOf`, `published_at < asOf`를 모두 만족해야 한다.
- 삭제: `deleted_at IS NULL OR deleted_at > asOf`. 선택 시점 이후 삭제된 기사는 과거 조회에 포함한다.
- 이슈 집계·대표 기사: `issue_assigned_at <= asOf`를 추가한다. 기사만 저장되고 이슈가 아직 배정되지 않은 시점에는 일반 기사 조회에만 포함한다.
- 이슈 상세: `issue.created_at <= asOf`. 이후 생성된 이슈는 404를 반환한다.
- 최근 24시간 집계: 발행일 범위 `[asOf - 24시간, asOf)`.
- 누적 집계·테마/이슈 대표 기사·주요 이슈: 기존 누적 범위를 유지하고 선택 시점 상한만 적용한다.
- 뉴스 목록: 기존 `from` 포함, `to` 날짜 포함 조건에 시점 상한을 추가한다. 교집합이 없으면 빈 목록이다. 전체 개수와 목록에 동일한 조건을 적용한다.
- 인기 테마 시간별 차트: 기존처럼 선택 시각의 시간대를 포함한 정시 단위 24개 구간을 반환한다. 마지막 구간은 `asOf`까지만 집계한다. 따라서 정확한 최근 24시간 집계와 시작 경계가 다를 수 있다.
- 국가·분야·테마는 고정 분류 정보로 유지한다. 뉴스 국가 필터만 해당 시점의 조회 가능한 기사 기준으로 제공한다.

## 화면 연동

상단 타임머신 탭에서 2026-09-06부터 한국 시간 기준 오늘까지 날짜를 선택한다. 이동 버튼을 누른 시각의 시·분·초를 선택 날짜에 적용한다.

약 5.2초 동안 기존 우주 화면의 지구본을 역회전시키고 그 위에 궤도 링을 표시한다. 오른쪽 데이터는 위로 빠르게 흘러가는 효과를 적용한다. 별도 전체 화면이나 두 번째 지구본은 만들지 않는다. 뉴스 화면에서 시작하면 먼저 대시보드로 이동한다. 도착 시 `asOf`를 전환하고 글로벌 동향 데이터를 요청한다. 연출 건너뛰기를 지원하며, 모션 감소 설정에서는 0.7초 전환을 사용한다.

우주 화면 왼쪽 위에 `2026년 9월 17일 1시 30분` 형태로 한국 시각을 표시한다. 현재 모드에서는 시간이 갱신되고, 과거 모드에서는 조회 시점에 고정되며, 시간 이동 중에는 출발 시각부터 도착 시각까지 되감긴다.

브라우저는 같은 `asOf`를 대시보드·국가·테마·이슈·뉴스 목록·상세·필터 요청에 전달한다. URL에 시각을 보존하여 화면 이동과 새로고침에도 유지한다. 시점 변경 시 선택한 상세와 이전 요청을 정리하되 지구본은 재생성하지 않는다. 과거 모드의 주기적 새로고침은 중단한다. 상단의 현재로 버튼으로 실시간 모드에 돌아갈 수 있다.

## 한계

현재 저장된 시간 정보로 당시 데이터를 재계산하며 DB 스냅샷을 재현하지 않는다. `issue_assigned_at`과 이슈 생성 시각은 기존 이벤트 시각이므로 지연 수신 시 실제 화면에 나타난 시점과 차이가 있을 수 있다. 수집 경로의 덮어쓰기 동작은 변경하지 않았으며, 데이터 불변 전제가 깨지면 과거 결과도 달라진다. 순위 계산식의 과거 버전은 보존하지 않는다.

삭제 시점 조건 때문에 기존 `deleted_at IS NULL` 부분 인덱스만으로 과거 조회 전체를 처리할 수 없다. 인덱스 추가는 실행 계획을 측정한 뒤 결정한다.
