## 2. 화면 이동

> `[x] C. 둘 다: 한 번 클릭=필터, 더블클릭/버튼=상세 전환`

**클릭/더블클릭 분기는 그대로 넣었습니다(240ms).** 다만 **한 번 클릭에서 '필터'를 뺐습니다.**

- 한 번 클릭 → `onSelectCountry` → `highlight` prop으로 국경만 강조(줌 없음). 어느 화면에서나 같습니다.
- 더블클릭 → `onOpenCountry` → 국가 분석 화면 + 카메라 포커스 + 이슈 핀

### 국가 필터(`scope`)를 없앤 이유

원래는 한 번 클릭이 목록을 그 나라로 좁히는 필터였습니다(`scope`). 그 필터는 계층 이동으로
풀리지 않는 직교축이라, 국가 분석에 들어갔다 뒤로 나오면 필터만 남았습니다. 결과가
**글로벌 동향에 "한국이 다룬 이슈 TOP 5"** — 세계 전체를 보는 화면에 한 나라 목록이 놓였습니다.
같은 목록이 어떤 때는 전체, 어떤 때는 한 나라 기준이니 지금 무엇을 보는지도 읽기 어려웠습니다.

그래서 **국가에 대한 정보는 국가 분석 화면 하나가 맡습니다.**

| 무엇 | 전 | 후 |
|---|---|---|
| 지구본 한 번 클릭 | 목록을 그 나라로 좁힘 | 지구본에 표시만 (`pick`) |
| 대시보드 목록 제목 | "○○이 다룬 이슈 TOP 5" | **"실시간 이슈 TOP 5"** (항상 전체) |
| 필터 칩 `ScopeChip` | 모든 화면 위에 | 삭제 |
| 좌표 `scope` | 국가축 | 삭제 — 축이 분류축 하나로 줄었습니다 |
| 패널 배경 톤(4-1) | 국가 필터 × 이슈·테마·분야 | 국가 분석 화면의 전반 논조만 |
| 국가 × 이슈를 겹쳐 보는 자리 | 패널 배경 그라데이션 | 이슈 화면의 **국가별 논조** 목록 |

`pick`은 `spot`처럼 `App`의 지역 상태입니다. 화면을 옮기면(`go`) 같이 비워지고,
헤더 '국가 분석' 탭이 들어갈 기본값이 됩니다 — 지구본에서 고른 나라로 들어갑니다.

이슈 화면의 산포도에서 점 하나만 크게 그리던 강조도 `scope` 대신 `spot`이 맡습니다.
목록에서 나라를 누르면 지구본이 돌고, 그 나라 점이 커지고, 줄에 호박색 표식이 붙습니다.

`GlobeThree`에 `highlight` prop과 `setHighlight()` API를 새로 추가했습니다.
기존 `focus`는 줌·핀까지 하지만 `highlight`는 윤곽만 바꿉니다 —
표시했을 뿐 화면을 옮긴 게 아니기 때문입니다.

| 결정 | 반영 |
|---|---|
| 2-1 뒤로 가기 버튼만 | 그대로. URL은 안 건드립니다. 다만 아래처럼 구조를 바꿨습니다 |
| 2-2 패널이 각자 스크롤 | 그대로. 스테이지 고정, 패널만 `overflow-y: auto` |

### 2-1 — 뒤로가기를 히스토리가 아니라 계층으로 다시 정의

처음엔 화면을 이름(`{name:'issue', id}`)으로 들고 다녔습니다.
그러면 뒤로가기 목적지를 화면 종류로 추론하게 되는데, 이 앱의 이동 그래프는
트리가 아니라 그래프여서 "국가 → 테마 → 이슈 → 뒤로 = 대시보드"처럼 두 계단을 건너뛰고
국가 필터까지 잃었습니다.

`src/navigation.js`를 새로 만들어 **화면을 좌표로** 표현하고,
뒤로가기를 "가장 안쪽 칸 하나 비우기"로 정의했습니다. 자세한 규칙은 README에 있습니다.

곁들여 `TaxonomyPath`(원래 장식이었던 분류 경로)를 클릭 가능하게 만들어,
뒤로가기를 여러 번 누르는 대신 원하는 칸으로 한 번에 점프할 수 있게 했습니다.

**그 다음 한 번 더 고쳤습니다.** 처음엔 브레드크럼을 좌표 전체로 만들어
`국가 › 분야 › 테마 › 이슈`를 한 줄에 늘어놨는데, 국가는 계층이 아니라 필터라서
분류 체계가 국가 밑에 매달린 것처럼 읽혔습니다. 그리고 분야는 갈 화면이 없어
브레드크럼에만 떠 있었습니다 — 결정표 1-3의 3단이 실제로는 2단이었던 셈입니다.

- 브레드크럼은 **분류 축만** 그립니다. 국가는 필터 칩으로 분리했고, 칩은 모든 화면에 보입니다.
- **분야 화면을 만들었습니다.** 대시보드에 분야 칩(입구)을 놓고,
  테마 전체 목록도 분야별로 묶었습니다.
- 현재 위치 크럼도 값을 보여줍니다. 예전엔 `[이슈]` 라벨만 덩그러니 남았습니다.

## 4. 지구본

| 결정 | 반영 |
|---|---|
| `GlobeThree` (3D) | 그대로 |
| 4-1 지구본 ↔ 패널 배경 전환 | 그대로. 우호=초록 / 비판=빨강 그라데이션 |
| 별 배경 `StarField` | 미사용 — 흰 배경에서는 별이 보이지 않는다 |
| 대기 글로우 | 그대로 (`GlobeThree` 내장) |
| 국가 포커스 외곽선 + 이슈 핀 | 그대로 |
| 국가 포커스 자세 | 요(경도) + 피치(위도), 롤 0 — **북쪽이 위로 오는 세계지도 자세** |
| 별똥별 | 미사용 (`meteorInterval` 기본 0) |
| 상호 언급 아크 | 미사용 |
| 자전 on/off 버튼 | 미사용 (`spinControl={false}`) — 자전 자체는 유지 |
| 논조 목록의 국가 클릭 | **화면을 옮기지 않는다** — 지구본 시점만 그 나라로 돌린다(다시 누르면 해제) |
| 지구본 한 번 클릭 | 어느 화면에서나 표시만. 국가 필터는 없앴습니다(2장) |

논조 목록(`ToneScatter`)에서 나라를 누르면 국가 분석으로 넘어가던 동작을 뺐습니다.
"이 나라가 어디였지"를 확인하려고 누른 것인데 보던 이슈를 빼앗기고, 돌아오려면
뒤로가기를 밟아야 했습니다. 이제 그 클릭은 카메라만 움직입니다 —
지구본이 그 나라를 향하고, 줄 왼쪽에 지구본 포커스와 같은 호박색 표식이 붙습니다.

시점은 `view` 좌표가 아니라 `App`의 지역 상태(`spot`)입니다. 스크롤 위치와 같은 급이라
뒤로가기 사다리(2-C)에 끼면 계단이 하나 늘어납니다. 화면을 옮기면(`go`) 같이 비워집니다.
국가 분석으로 들어가는 길은 지구본 더블클릭과 필터 칩이 그대로 맡습니다.

국가 포커스는 최단호 회전(`setFromUnitVectors`)을 쓰지 않습니다. 나라는 정확히 가운데 오지만
그 회전에는 롤이 섞여서, 한국을 누르면 지도가 시계방향으로 **약 88°** 누웠습니다 —
서쪽(UAE·카타르)이 화면 위에 붙은, 세계지도와 다른 그림이었습니다.
지금은 요 `-(lon+90)` + 피치 `lat`, 롤 0으로 세웁니다(`orientTo`). 7개국 모두 기울기 0°입니다.
드래그(`onMove`)도 요·피치만 건드리므로, 두 길이 같은 자세를 만듭니다 —
피치 한계 `PITCH_LIMIT`(0.9rad)도 같이 씁니다.

지구본은 `spot ?? view.country` 순서로 봅니다 — 시점이 `country`를 이깁니다.
(한 번 클릭한 표시는 `highlight`라 이 순서와 별개입니다.)
국가 분석에서 테마·이슈로 내려오면 `country` 칸이 뒤로가기 사다리 때문에 그대로 차 있는데,
그게 시점을 이기면 그 경로로 들어온 이슈 화면에서만 클릭이 먹지 않습니다 —
같은 화면이 들어온 길에 따라 다르게 움직이는 셈입니다. 시점을 풀면 `view.country`로 떨어져
원래 보던 나라로 되돌아갑니다.

### 대시보드 아래 두 블록을 뺀 이유

글로벌 동향은 이제 지표 2칸 + 실시간 이슈 TOP 5 + 원문 미저장 고지로 끝납니다.

코드는 지우지 않고 `components/panel/DashExplore.jsx`로 옮겨 뒀습니다
(`FieldNarrow`, `RisingThemes`). 데이터는 두 컴포넌트가 직접 모델에서 읽고,
부르는 쪽은 눌렀을 때 갈 곳만 넘깁니다 — 다시 붙일 때 `DashScreen`에 두 줄이면 됩니다.

    <FieldNarrow onSelect={(id) => go(toField(view, id))} />
    <RisingThemes onAll={() => go(openAside(view, 'themes'))} />

**딸려 사라진 입구가 있습니다.** 분야 화면과 '급상승 테마 전체'로 가는 대시보드 입구가
그 두 블록이었습니다. 둘 다 다른 길로는 여전히 갑니다 —
분야는 이슈·테마에서 브레드크럼으로 올라가거나 '테마 분석' 화면의 '이 분야만 보기'로,
테마 전체는 국가 분석의 '급상승 테마 → 전체 보기'로 갑니다.
대시보드에서 바로 가는 길이 필요해지면 위 두 줄을 되돌리면 됩니다.

### 5-5를 확장한 이유

`ToneSpark`는 점만 찍습니다. 그런데 6번에서 **표본 부족 처리**와 **편차 경고**도
가져가기로 했는데, 그 둘이 붙을 자리가 없었습니다.
그래서 `ToneScatter`를 새로 만들어 셋을 한 블록에 넣었습니다.

- 산포 점 (신문) — 표본이 충분한 나라만 찍습니다
- 국가별 행: 표본 수 · 오늘 논조 · 평시 기준선 · 값 또는 `표본 부족` (코스모스)
- 편차가 좁은 나라 경고 (신문)
- "평균을 쓰지 않는 이유" 각주 (신문)

## 6. 태도

가져가기로 한 것:

| 태도 | 반영 |
|---|---|
| 평균을 쓰지 않는다 | `ToneScatter`가 분포만 보여주고 각주로 이유를 적습니다 |
| 매체 간 편차 경고 | `ToneScatter` 안 경고 상자 (`spreadOf < 0.10`) |
| 표본 부족 처리 | 30건 미만이면 값 대신 `표본 부족` |
| 원문 미저장 고지 | `PolicyNote` — 대시보드·이슈·국가 화면 하단 |
| 논조 모드 잠금 | `StageHead` — 이슈 맥락이 없으면 스위치가 라벨로 내려앉습니다 |

체크 안 한 것(수집 편중 경고 / 다루지 않은 이슈 목록 / 빈 상태 이유 / 채점 근거)은
**반영하지 않았습니다.** 데이터에는 근거가 남아 있으니(`C(id).m`, 이슈별 `tone` 누락 여부)
나중에 붙일 수 있습니다.

버리기로 한 것:

| 버린 것 | 반영 |
|---|---|
| 사용자 프로필·로그인 | 없음 |
| 기간 선택 버튼 | `PanelTopline`을 버튼 → 라벨로 바꿨습니다 |
| 정렬 버튼 | `ArticleFilterBar`에서 제거. 논조 필터만 남았습니다 |

## 결정표에 없어서 제가 정한 것

결정표에 항목이 없던 것들입니다. 다르게 하고 싶으시면 알려주세요.

1. **관심도 계산식** — 원본 공식(국가 인덱스 기반)이 "한국의 1위 관심국 = 남아공" 같은
   결과를 내서, 겹치는 보도 주제로 다시 정의했습니다.
2. **기사 논조** — 원본 기사 데이터에 논조 값이 없어서,
   그 나라의 테마 논조 + 결정적 해시 편차로 만들었습니다.
3. **테마 10개 / 이슈 13개의 구성** — 4개 분야를 다 채우려고 정했습니다.
4. **국가 화면의 톤 설명 문구** — 배경색만 바뀌면 이유를 알 수 없어서 한 줄 붙였습니다.
4-1. **논조 색 스케일 전체를 초록–회색–빨강으로 통일** — 배경만 초록/빨강으로 바꾸면
   바로 옆 뱃지·점·지구본은 파랑이라 같은 값이 자리마다 다른 색으로 보입니다.
   `toneRGB()`와 `--wtw-pos/neu/neg`를 한꺼번에 바꿨습니다.
4-2. **표본 부족 색을 보라로** — 초록이 '우호'를 가져갔으므로,
   기존의 민트(초록 계열)를 그대로 두면 '표본 부족'이 '우호'로 읽힙니다.
   논조 스케일 밖의 색이어야 해서 보라로 옮겼습니다.
5. **필터 칩(`ScopeChip`)** — 2-C를 고르면 "지금 필터가 걸렸다"를 보여줄 자리가 필요합니다.
6. **`StageFoot`** — 톤 색 축과 표본 부족 범례를 놓을 자리.
