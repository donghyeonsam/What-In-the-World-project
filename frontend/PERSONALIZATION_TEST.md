# 사용자 개인화 프론트 체험

브랜치: `feature/front-custom-user`

## 로컬 실행 (Windows PowerShell)

프로젝트 루트에서:

```powershell
cd frontend
npm.cmd ci
$env:API_PROXY_TARGET = 'https://dev.witw.kro.kr'
npm.cmd run dev -- --host 127.0.0.1
```

브라우저에서 http://127.0.0.1:5174 를 연다. 포트가 사용 중이면 Vite가 출력한 주소를 사용한다.
개발 서버의 API를 프록시하므로 별도 백엔드는 필요 없다. 개발 서버 접속이 가능한 네트워크가 필요하다.
로컬 백엔드로 전환하려면 `API_PROXY_TARGET`을 `http://localhost:8080`으로 바꾸고 Vite를 재시작한다.

주의: 이 방식은 **실제 개발 서버 계정**을 사용한다. 회원가입·비밀번호 변경은 개발 서버 DB에 반영된다.

## 계정 없이 확인하기 (테스트 전용 서버)

실제 계정을 만들거나 바꾸지 않고 로그인 이후 화면을 보려면 고정 응답 서버를 쓴다.

```powershell
npm.cmd run build
npm.cmd run test:browser-server
```

http://127.0.0.1:5175 에서 아래 계정으로 로그인한다. (다른 포트: `$env:PORT = '5176'`)

- 이메일: `preview@example.com`
- 비밀번호: `preview1234`

회원가입·이메일 인증·비밀번호 변경은 이 서버에서 동작하지 않는다. 로그인·로그아웃·관심사·뉴스함만 확인한다.

## 확인 순서

1. 비로그인 상태: 상단 우측에 국가 검색과 사용자 아이콘만 보이고 뉴스함 아이콘은 없어야 한다.
2. 사용자 아이콘을 누르면 마이페이지가 아니라 "로그인 / 회원가입" 모달이 열린다.
3. 회원가입 탭: 이메일 입력 → 인증번호 보내기 → 영문·숫자 7자리 입력 → 인증하기 → 비밀번호(8~72자) 입력 → 회원가입. 완료되면 로그인 탭으로 전환되고 안내가 표시된다.
4. 로그인하면 모달이 마이페이지로 바뀌고 상단에 뉴스함 아이콘이 나타난다. 이후 사용자 아이콘을 누르면 모달 대신 **마이페이지 / 로그아웃 드롭다운**이 열린다. 바깥 클릭이나 Escape로 닫힌다.
5. 관심사 설정 탭: 테마 키워드를 분야별 드롭다운에서 선택한다(최대 10개). 선택한 항목은 칩으로 표시되고, 칩의 × 를 누르면 해제된다. 이미 선택한 항목은 드롭다운에서 사라진다. 국가 선택은 없다.
6. 모달을 닫고 테마 또는 이슈 상세로 이동하면 관심 등록 버튼이 있다. 등록한 이슈는 마이페이지의 관심 이슈 목록에 나타난다.
7. 뉴스 구독함: 상단에 **전체 / #테마** 탭이 있다. 전체 탭은 모든 관심사의 기사를 발행순으로 모으고(중복 제거), 테마 탭은 그 테마의 기사만 보여준다. 기사 제목을 누르면 요약과 원문 링크가 표시된다. "이전 뉴스 더 보기"로 범위를 늘릴 수 있다. 모달은 화면 중앙에 뜬다.
8. 모든 관심 항목을 해제하면 뉴스 구독함에 안내와 "구독 관리" 버튼만 표시된다.
9. 비밀번호 변경 탭: 현재 비밀번호와 새 비밀번호를 입력해 변경한다. 성공하면 서버가 세션을 종료하므로 로그인 화면으로 돌아가며 안내가 표시된다. 새 비밀번호로 다시 로그인한다.
10. 드롭다운 또는 마이페이지의 로그아웃을 누르면 뉴스함 아이콘이 사라지고 사용자 아이콘은 다시 로그인 모달을 연다.
11. 모달의 우측 상단 × 버튼, Escape, 바깥 클릭, Tab 키 이동을 확인한다. 내용을 스크롤해도 제목과 × 버튼은 상단에 남아야 한다. 전체 뉴스 화면에서도 두 아이콘을 사용할 수 있다.
12. 새로고침 후 로그인 상태와 관심 설정이 유지되는지 확인한다.

## 범위

- 로그인·회원가입(이메일 인증)·로그아웃·비밀번호 변경은 실제 백엔드 API를 사용한다. 세션 쿠키 기반이며 만료되면 자동으로 로그인 화면으로 돌아간다.
- 관심 설정은 **계정 ID별로 현재 브라우저의 localStorage**에 저장한다. 서버 저장 API가 없어 다른 기기와는 동기화되지 않는다.
- 테마 최대 10개, 이슈 최대 10개. 기존 테마·이슈 ID만 사용하며 자유 입력 키워드는 지원하지 않는다. 국가 구독은 제공하지 않는다(이전에 저장된 국가 설정은 무시된다).
- 뉴스 구독함은 기존 기사 목록 API(`/articles`)로 테마별 최근 12건씩 조회한다(더 보기로 최대 100건). 관심 이슈는 이슈 개요의 대표 기사(최대 10건)를 함께 표시한다.
- 실시간 알림, 읽음 상태, 미확인 개수는 포함하지 않는다.
- 외부(소셜) 계정은 비밀번호 변경 대신 해당 서비스에서 변경하도록 안내한다.
- 일부 항목 조회가 실패하면 실패한 항목만 표시하고 성공한 항목의 기사는 계속 보인다.
